# Frozen reproduction evidence

Generated by `scripts/paper.py freeze-evidence`.

- `environment.json`: runtime, package, accelerator, git, and manifest provenance.
- `subject_folds.csv`: immutable subject label and CV-fold assignment.
- `historical_subject_folds.csv` and `fold_comparison.json`: prior manuscript fold map and drift audit, when supplied.
- `catalog.json`: canonical 97-cell experiment specification.
- `model_configurations.json`: declared hyperparameters and methods notes.
- `repository.patch`: exact uncommitted code state relative to the recorded commit.
- manuscript PDF: frozen submitted manuscript snapshot when supplied.
- `checksums.sha256`: hashes for lockfiles, manifest, and generated result artifacts.
